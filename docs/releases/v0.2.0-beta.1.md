# GrainBernik v0.2.0-beta.1

Unofficial patch of GrainBrick 1.0.1 for the Anbernik RG40XX H.
The official closed GrainBrick application is **not** included: get
`grainbrick.beta.1.0.1.zip` from the
[original author's release](https://github.com/ETRNLIAM/GrainBrick/releases/tag/v1.0.1-beta.2).

## What's new

- **RG40XX H as a two-way USB sound card for iPhone** (official ROCKNIX
  20261101, DDR4 image): GrainBrick plays to the headphones and the iPhone at
  the same time, records the iPhone into SAMPLE, input monitoring (SELECT while
  recording). USB audio starts automatically when IPHONE mode is chosen.
- **Simpler SETTINGS:** AUDIO, AUDIO / ADVANCED, CONTROLS (presets),
  CONTROLS / ADVANCED, OTHER SETTINGS. USB audio devices are detected on
  hot-plug; lists wrap around; in editors A = +, B = −.
- **Sticks & Buttons:** L3/R3 stick clicks as separate controls, step actions
  Octave + / Octave −, new effects (Octave Up, Shimmer Burst, Grain Burst,
  Lo-Fi, Stutter), six presets using all six controls.
- **Delete recordings** in the SAMPLE browser (SELECT twice); the loaded
  sample is protected.
- **Fixes:** exit hang on Select + Start (pygame mixer disabled, stalled audio
  worker cleaned up); INTERNAL output returns to the console after the iPhone
  is unplugged; interrupted USB recordings get a valid WAV header before the
  editor opens (saving no longer exhausts memory); ROCKNIX A/B and X/Y labels.

Known: iOS shows "Accessory uses too much power" because the console draws
power from the iPhone; audio works, a USB-C hub with PD pass-through removes
the warning. KNULLI cannot run the iPhone mode (kernel limitation).

## Downloads

- **GrainBernik-v0.2.0-beta.1-RG40XXH-patch.zip** — adapters, ROCKNIX scripts,
  prebuilt UAC2 modules, build tools and README (EN/RU). Fresh ROCKNIX install:
  `sh rocknix/make_package.sh grainbrick.beta.1.0.1.zip grainbernik-rocknix`,
  copy the folder to `/storage/` and run `install.sh` (see README).
- **GrainBernik-v0.2.0-beta.1-RG40XXH-update.zip** — existing installation:
  copy `grainbrick-beta/*` into `/storage/roms/ports/grainbrick beta 1.0.1/`
  and `rocknix/GrainBrick beta 1.0.1.sh` into `/storage/roms/ports/`
  (KNULLI: only `grainbrick-beta/*`, keep your KNULLI launcher).
- `SHA256SUMS.txt`, `verification.json` — checksums and source commit.

# GrainBernik v0.2.0-beta.1 (русский)

Неофициальный патч GrainBrick 1.0.1 для Anbernic RG40XX H. Закрытое приложение
GrainBrick в архивы **не входит** — скачайте `grainbrick.beta.1.0.1.zip` у
[автора](https://github.com/ETRNLIAM/GrainBrick/releases/tag/v1.0.1-beta.2).

## Что нового

- **RG40XX H — двусторонняя USB-звуковая карта для iPhone** (официальный
  ROCKNIX 20261101, образ DDR4): звук GrainBrick одновременно в наушниках и в
  iPhone, запись с iPhone в SAMPLE, мониторинг входа (SELECT во время записи).
  USB-звук включается сам при выборе режима IPHONE.
- **Упрощённое SETTINGS:** AUDIO, AUDIO / ADVANCED, CONTROLS (пресеты),
  CONTROLS / ADVANCED, OTHER SETTINGS. USB-устройства звука определяются при
  подключении; списки по кругу; в редакторах A = +, B = −.
- **Стики и кнопки:** нажатия L3/R3 как отдельные органы, шаговые Octave + /
  Octave −, новые эффекты (Octave Up, Shimmer Burst, Grain Burst, Lo-Fi,
  Stutter), шесть пресетов на все шесть органов.
- **Удаление записей** в браузере SAMPLE (дважды SELECT); загруженная запись
  защищена.
- **Исправления:** зависание при выходе по Select + Start (микшер pygame
  выключен, зависший аудиопроцесс завершается); выход INTERNAL возвращается на
  консоль после отключения iPhone; прерванная USB-запись получает корректный
  заголовок WAV до открытия редактора (сохранение больше не исчерпывает память);
  подписи A/B и X/Y на ROCKNIX.

Известно: iOS пишет «Аксессуар использует слишком много энергии», так как
консоль берёт питание от iPhone; звук работает, USB-C хаб с проходной зарядкой
(PD) убирает предупреждение. На KNULLI режим iPhone невозможен (ограничение ядра).
