# GrainBernik v0.1.1-beta.1

## Shutdown hotfix — 2026-11-06

The existing release downloads have been refreshed with the Select + Start
shutdown fix, including the current ROCKNIX / iPhone USB audio adapters.
The release tag remains at the original compatibility update; refreshed
archive sources are identified by `source_commit` in `verification.json`.

- Fixed a ROCKNIX exit hang in the unused Pygame PulseAudio mixer. GrainBrick
  playback/recording still uses ALSA/PipeWire through aplay/arecord.
- Added recovery when native audio-worker shutdown leaves a blocked playback
  process alive. Only that worker and its own aplay children are stopped.
- Tested over SSH on RG40XX H / official ROCKNIX 20261101: Select + Start
  and Start + Select both exit normally (code 0), without leftover processes.
- 96 automated tests passed; 28 optional native integration tests skipped.
  Native shutdown and ordinary Wayland launch were verified separately.
- An audible iPhone round-trip was not retested for this hotfix.

## Downloads and installation

**GrainBernik-v0.1.1-beta.1-RG40XXH-patch.zip** contains the current adapters,
ROCKNIX packaging/installation scripts and prebuilt UAC2 kernel modules,
plus English/Russian instructions. For a fresh ROCKNIX installation, extract
it and follow README.md (`rocknix/make_package.sh` requires your official
GrainBrick ZIP).

**GrainBernik-v0.1.1-beta.1-RG40XXH-update.zip** is for an existing installation:

- ROCKNIX: copy the contents of `grainbrick-beta/` into
  `/storage/roms/ports/grainbrick beta 1.0.1/`, and copy
  `rocknix/GrainBrick beta 1.0.1.sh` into `/storage/roms/ports/`.
  **Both steps are required** to fix the exit hang.
- KNULLI: merge `grainbrick-beta/` into your existing app directory; keep
  your current KNULLI launcher. The ROCKNIX launcher is only for ROCKNIX.
- Back up replaced files. Keep settings, samples, projects and recordings.

`SHA256SUMS.txt` and `verification.json` identify the refreshed archives and
payload. The official closed GrainBrick application and DSP binaries are not
included or modified. Obtain `grainbrick.beta.1.0.1.zip` from the
[original author's release](https://github.com/ETRNLIAM/GrainBrick/releases/tag/v1.0.1-beta.2).

### Как обновиться

Скачайте **GrainBernik-v0.1.1-beta.1-RG40XXH-update.zip**.

- **ROCKNIX:** содержимое `grainbrick-beta/` скопируйте в
  `/storage/roms/ports/grainbrick beta 1.0.1/`, а файл
  `rocknix/GrainBrick beta 1.0.1.sh` — в `/storage/roms/ports/`.
  **Нужны оба шага**, иначе исправление выхода будет неполным.
- **KNULLI:** объедините `grainbrick-beta/` с установленной папкой приложения;
  оставьте свой загрузчик KNULLI. Загрузчик ROCKNIX предназначен только для ROCKNIX.
- Сделайте резервную копию заменяемых файлов. Настройки, сэмплы, проекты и записи
  сохраняются: в архиве нет файлов пользовательских настроек.

Для новой установки используйте **RG40XXH-patch.zip** и инструкцию README_RU.md.
Оригинальное закрытое приложение и его DSP-бинарники в архивы не входят.
Контрольные суммы обновлены в `SHA256SUMS.txt` и `verification.json`.
