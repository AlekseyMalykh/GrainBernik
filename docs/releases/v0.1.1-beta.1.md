# GrainBernik v0.1.1-beta.1

Compatibility update for the official GrainBrick v1.0.1-beta.2 release.

## Downloads

- **GrainBernik-v0.1.1-beta.1-RG40XXH-patch.zip** — RG40XX H adapters and
  installation instructions for a fresh install over official GrainBrick
  beta 1.0.1.
- **GrainBernik-v0.1.1-beta.1-RG40XXH-update.zip** — updated launcher and
  adapter files for an existing GrainBernik installation. Keep the old app
  folder until the new installation has been checked.
- **SHA256SUMS.txt** — archive and manifest hashes.
- **verification.json** — source and payload hashes.

The official GrainBrick application is not included. Download
`grainbrick.beta.1.0.1.zip` from the [author's release page](https://github.com/ETRNLIAM/GrainBrick/releases/tag/v1.0.1-beta.2).

## Integration details

GrainBrick 1.0.1 bundles NumPy and adds adaptive resolution, Anbernic control
support, and automatic USB audio input detection. The GrainBernik launcher
uses the bundled NumPy and system Pygame, loads the button and Advanced
Settings adapters, and leaves upstream display and USB audio handling active.
The older display and USB recording adapters are available through
`GRAINBERNIK_FIT=1` and `GRAINBERNIK_LEGACY_AUDIO=1` respectively. RG40XX H
has not been confirmed by the original author for GrainBrick 1.0.1, so this
integration still needs on-device verification.

No application or DSP binaries are modified or redistributed here. Automated
tests were not run for this update.

### Что объединено

В GrainBrick 1.0.1 NumPy включён в архив; добавлены адаптивное разрешение,
поддержка управления Anbernic и автоматическое определение USB-аудио. Загрузчик
GrainBernik использует встроенный NumPy и системный Pygame, загружает адаптеры
кнопок и расширенных настроек, оставляя штатные экран и USB-аудио активными.
Старые адаптеры доступны по переменным `GRAINBERNIK_FIT=1` и
`GRAINBERNIK_LEGACY_AUDIO=1`. Автор отдельно не подтверждал RG40XX H для
GrainBrick 1.0.1, поэтому объединение ещё нужно проверить на приставке.

Бинарники приложения и DSP не изменяются и не распространяются. Автотесты для
этого обновления не запускались.
