# GrainBernik v0.1.0-beta.1

First packaged GrainBernik beta release for **Anbernic RG40XX H / KNULLI**.

## Downloads and installation

- **GrainBernik-v0.1.0-beta.1-RG40XXH-patch.zip:** all six adapters, button-setup
  and USB-audio diagnostic port scripts, English/Russian instructions and
  detailed Advanced Settings documentation. Install the
  [official GrainBrick beta 1.0](https://github.com/ETRNLIAM/GrainBrick/releases)
  first, then copy the files in `rg40xx-h-patch/` to `roms/ports/` as described
  in the included README.
- **GrainBernik-v0.1.0-beta.1-RG40XXH-update.zip:** just the two Advanced Settings
  modules and updated launcher under `grainbrick-beta/`, plus `UPDATE.md`.
  For an existing GrainBernik installation, merge this folder into
  `/userdata/roms/ports/`. Preserve your audio/display/button adapters, USB
  helper scripts, configuration and user data.
- **SHA256SUMS.txt:** checksums of the release archives and verification report.
- **verification.json:** payload checksums and automated-check provenance.

Back up your launcher, settings, samples, projects and recordings before
updating. Do not delete or format the card. Original proprietary application
binaries, samples and personal configuration are not included in either ZIP.
Requires the official ARM64 application with KNULLI Python 3.12, Pygame and NumPy.

## Included features

- Full-screen 1024×768 to 640×480 adaptation, physical-button calibration and
  USB recording adaptation for RG40XX H.
- In-app **Settings → Advanced Settings**: independent Left Stick, Right Stick,
  L2 and R2 assignments, all OFF by default. Existing assignments survive updates.
- **31 XY parameters** from the running engine: grain, delay, reverb, shimmer,
  tape, roam and **13 ORBIX controls**. Each axis supports None, deadzone,
  sensitivity, inversion, Spring/Latch and smoothing. Musical ORBIX selections
  are quantized to valid integers.
- **Hold/Toggle** buttons: Freeze (native Motion Hold), Reverse, Delay Throw,
  Reverb Wash, Pitch Drop, Bypass, ORBIX and None. Overlapping assignments unwind
  correctly, and temporary effects release on entering menus or leaving the app.
- **Five factory control layouts**: Granular, Ambient, Echo, Tape and ORBIX Play.
  Applying one preserves stick calibration. The first factory use archives the
  old layout into an empty User slot; later uses never overwrite an occupied slot.
- **One User slot:** confirmed Save Current / Load User, independent snapshot,
  restart persistence and rollback after a failed preset save. Reset to Defaults
  preserves the saved User slot.
- **START** operates playback from every advanced page; **L1/R1** switches native
  tabs while retaining saved assignments, including from preset confirmations.
- **EN/RU contextual help** follows INFO LANGUAGE. Explanations appear above the
  control list; navigation hints remain at the bottom. Includes a full Russian README.

## Validation and limits

**48 automated checks pass:** 30 control/configuration tests and 18 integration
tests with the original ARM64 application, native input/renderer and DSP.
Checks include ORBIX generating sound from a silent input sample, preset
migration/save/load/cancellation/rollback, input ownership and EN/RU 640×480 renders.
The three update modules match the files written to the owner's card.

The owner reported successful operation of Advanced Settings on RG40XX H.
The complete per-feature and long-session hardware checklist has not been
individually recorded; this remains a beta release. Filter Cutoff/Resonance,
Tape Speed, Pan and direct Stutter/Tape Stop/Glitch are not exposed by the
verified API and are not offered. Delay Throw/Reverb Wash are parameter macros,
not a separate send/return system. ORBIX needs normal transport playback.

## Русский

Первый релиз GrainBernik в виде готовых архивов для **Anbernic RG40XX H / KNULLI**.

**Что скачать:**

- **patch.zip:** полный набор адаптеров, настройка кнопок, диагностика USB-звука
  и инструкции на двух языках. Сначала установите официальный GrainBrick beta 1.0,
  затем перенесите содержимое `rg40xx-h-patch/` в `roms/ports/` по инструкции.
- **update.zip:** обновление существующего GrainBernik только тремя файлами.
  Объедините папку `grainbrick-beta/` с установленной в `roms/ports/`.
  Существующие адаптеры звука/экрана/кнопок, USB-скрипты, настройки, сэмплы,
  проекты и записи сохраняются. Краткая инструкция находится в `UPDATE.md`.
- **SHA256SUMS.txt** и **verification.json:** контрольные суммы и сведения о проверках.

Перед установкой сделайте резервную копию загрузчика, настроек и пользовательских
данных. Не удаляйте установленную папку и не форматируйте карту. Оригинальное
закрытое приложение в комплект не входит; нужен официальный GrainBrick beta 1.0
и ARM64 KNULLI с Python 3.12, Pygame и NumPy.

**Что добавлено:**

- Встроенные расширенные настройки четырёх независимых органов управления.
- 31 назначение X/Y, включая 13 параметров ORBIX; None, мёртвая зона,
  чувствительность, инверсия, Spring/Latch и сглаживание.
- Freeze, Reverse, Delay Throw, Reverb Wash, Pitch Drop, Bypass и ORBIX
  для L2/R2 с Hold/Toggle и корректным снятием временных эффектов.
- Пресеты **Granular, Ambient, Echo, Tape, ORBIX Play** и один слот **User**.
  Применение, сохранение и загрузка требуют подтверждения. При первом выборе
  готового пресета пустой User сохраняет старую раскладку; занятый не заменяется.
  Сброс текущих назначений сохраняет User. При ошибке записи изменения отменяются.
- Исправлено управление **START и L1/R1** внутри расширенных настроек.
- Русские/английские подсказки в зависимости от INFO LANGUAGE, пояснения сверху
  как в штатных меню, полный русский README.
- В полный патч входят также адаптеры экрана, кнопок и USB-записи.

**Проверено:** проходят 48 автотестов, включая настоящий ARM64-модуль и DSP.
Обновление содержит те же три файла, которые записаны на карту владельца.
Работа Advanced Settings на RG40XX H подтверждена владельцем; полная аппаратная
проверка каждого пункта и длительных сессий отдельно не зафиксирована.

**Ограничения:** это beta. Filter Cutoff/Resonance, Tape Speed, Pan и отдельные
Stutter/Tape Stop/Glitch не добавлены без подтверждённого API. Freeze использует
штатный Motion Hold фрагментов. Delay Throw/Reverb Wash — наборы значений
существующих параметров, а не новая маршрутизация. ORBIX запускается обычным START.
