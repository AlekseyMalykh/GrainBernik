# GrainBernik v0.1.0-beta.2

Localization fix for the Advanced Settings added in GrainBernik v0.1.0-beta.1.

## Downloads

- **GrainBernik-v0.1.0-beta.2-RG40XXH-patch.zip** — full patch for a fresh
  installation over the official GrainBrick beta 1.0.
- **GrainBernik-v0.1.0-beta.2-RG40XXH-update.zip** — replaces only
  `gb_advanced.py`, `gb_advanced_controls.py` and `gb_launch.py` in an existing
  GrainBernik installation. Keep settings, samples, projects and recordings.
- **SHA256SUMS.txt** — SHA-256 checksums for the archives and manifest.
- **verification.json** — source and payload hashes. Automated tests were not
  rerun for this localization-only change; the 48 checks listed for beta.1 apply
  to that earlier revision.

Install the official [GrainBrick beta 1.0](https://github.com/ETRNLIAM/GrainBrick/releases)
first. The original closed application is not included. Requires ARM64 KNULLI,
Python 3.12, Pygame and NumPy. Back up user data before updating.

## Language behavior

The native **INFO LANGUAGE** setting (**EN/RU**) controls contextual parameter
descriptions and navigation/transport hints. Menu labels, option names, values,
confirmation titles and save-error messages remain in English.

This fix has not yet been retested on the RG40XX H. The beta.1 feature set was
previously reported working on that device; hardware verification of this change
is pending.

## Русский

Исправление языка интерфейса расширенных настроек GrainBernik v0.1.0-beta.1.

## Файлы релиза

- **GrainBernik-v0.1.0-beta.2-RG40XXH-patch.zip** — полный патч для новой
  установки поверх официального GrainBrick beta 1.0.
- **GrainBernik-v0.1.0-beta.2-RG40XXH-update.zip** — обновляет только
  `gb_advanced.py`, `gb_advanced_controls.py` и `gb_launch.py` в установленном
  GrainBernik. Настройки, сэмплы, проекты и записи сохраняются.
- **SHA256SUMS.txt** — SHA-256 контрольные суммы архивов и манифеста.
- **verification.json** — хэши исходников и содержимого. Автотесты для этой
  правки не запускались; 48 проверок из beta.1 относятся к предыдущей версии.

Сначала установите официальный [GrainBrick beta 1.0](https://github.com/ETRNLIAM/GrainBrick/releases).
Закрытое оригинальное приложение в патч не входит. Нужны ARM64 KNULLI, Python
3.12, Pygame и NumPy. Перед обновлением сохраните пользовательские данные.

## Правило языка

Настройка **INFO LANGUAGE** (**EN/RU**) меняет контекстные описания параметров
и подсказки управления. Названия меню, пунктов, значения, заголовки подтверждений
и ошибки сохранения остаются на английском.

Правка пока не проверялась повторно на RG40XX H. Работа функций beta.1 на этой
консоли ранее подтверждалась; аппаратная проверка этого исправления ожидается.
