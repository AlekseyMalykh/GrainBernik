# GrainBernik v0.3.0-beta.1

Unofficial add-on for **GrainBrick BETA 2.0** (tag `v2.0.0-beta.2`) on the
Anbernic **RG40XX H** with official **ROCKNIX 20261101** (DDR4 image).
This is a separate line: GrainBernik v0.2.x stays the choice for GrainBrick 1.0.1.
The closed GrainBrick application is **not** included — get
`GrainBrick_BETA_2_0.zip` from the
[original author](https://github.com/ETRNLIAM/GrainBrick/releases).

## What's new

- **GrainBrick BETA 2.0 on the RG40XX H / ROCKNIX.** New launcher
  `GrainBrick BETA 2.0.sh` (separate Python 3.12 + pygame, performance CPU mode,
  clean exit on Select + Start, ROCKNIX A/B and X/Y labels). It installs next to
  the 1.0.1 version; samples, projects, recordings and settings survive updates.
- **iPhone / USB audio** page in SETTINGS (*IPHONE / USB AUDIO*): the console is a
  two-way USB sound card for the iPhone (play to headphones and iPhone, record /
  process the iPhone sound in SAMPLE and LIVE). External devices such as the
  M-VAVE FM1 and Zoom H1n work. Verified on the console with an iPhone and an FM1.
- **STICKS & BUTTONS** page in SETTINGS: both sticks (X/Y), L2, R2 and the stick
  clicks L3/R3 as independent sound controls — **61 stick parameters, 29 button
  effects, 11 presets + User slot**, with new targets for **RHYTHM** (tempo),
  **ORBIX Rings**, **OSCILLATOR**, **LIVE** (input / master level) and
  **GRAIN 2/3** (randomisation). New presets: *Rhythm, Rings, Oscillator, Live,
  Grain 2/3*. The active preset is shown (a changed setup becomes `USER`);
  descriptions are in English and Russian.
- Both pages follow the BETA 2.0 **Console Controls**: A enters / edits, B goes
  back, LEFT/RIGHT edit, hold A + LEFT/RIGHT = quick edit.
- README rewritten (EN/RU) with install, controls, iPhone and STICKS & BUTTONS
  instructions; the 1.0.1 documentation moved to `docs/LEGACY_1_0_1*.md`.

## Known limitations

- Not ported from the 1.0.1 line yet: the shortened SETTINGS menu and
  **deleting recordings inside SAMPLE** (planned).
- Not measured yet: CPU load of the Rings resonator and LIVE on the H700,
  Bluetooth MIDI on ROCKNIX, iPhone and USB MIDI together on the one OTG port.
- RHYTHM pattern parameters are internal to RHYTHM; only the tempo is assignable.
- iOS may show "Accessory uses too much power"; a USB-C hub with PD
  pass-through removes it. KNULLI is not supported by this line.

## Downloads

- **GrainBernik-v0.3.0-beta.1-RG40XXH-patch.zip** — adapters, launcher, installer,
  prebuilt UAC2 modules, build tools, docs (EN/RU). Fresh install:
  `sh rocknix/make_package.sh GrainBrick_BETA_2_0.zip grainbernik-rocknix`,
  copy the folder to `/storage/` and run `install.sh` (see README).
- **GrainBernik-v0.3.0-beta.1-RG40XXH-update.zip** — existing 0.3 installation:
  copy `grainbrick-beta2/*` into `/storage/roms/ports/grainbrick-beta2/` and
  `rocknix/GrainBrick BETA 2.0.sh` into `/storage/roms/ports/`.
- `SHA256SUMS.txt`, `verification.json` — checksums and source commit.

# GrainBernik v0.3.0-beta.1 (русский)

Неофициальная надстройка для **GrainBrick BETA 2.0** (тег `v2.0.0-beta.2`) на
Anbernic **RG40XX H** с официальной **ROCKNIX 20261101** (образ DDR4). Это
отдельная линия: для GrainBrick 1.0.1 остаётся GrainBernik v0.2.x. Закрытое
приложение GrainBrick в архивы **не входит** — скачайте `GrainBrick_BETA_2_0.zip`
у [автора](https://github.com/ETRNLIAM/GrainBrick/releases).

## Что нового

- **GrainBrick BETA 2.0 на RG40XX H / ROCKNIX.** Новый запускатель
  `GrainBrick BETA 2.0.sh` (отдельные Python 3.12 + pygame, режим CPU performance,
  выход по Select + Start, подписи A/B и X/Y как на ROCKNIX). Ставится рядом с
  версией 1.0.1; сэмплы, проекты, записи и настройки сохраняются при обновлении.
- Страница **iPhone / USB audio** в SETTINGS (*IPHONE / USB AUDIO*): консоль —
  двусторонняя USB-звуковая карта для iPhone (звук в наушники и в iPhone, запись и
  обработка звука iPhone в SAMPLE и LIVE). Работают внешние устройства, например
  M-VAVE FM1 и Zoom H1n. Проверено на консоли с iPhone и FM1.
- Страница **STICKS & BUTTONS** в SETTINGS: оба стика (X/Y), L2, R2 и нажатия на
  стики L3/R3 как независимые органы управления звуком — **61 параметр для стиков,
  29 эффектов кнопок, 11 пресетов + слот User**, с новыми целями для **RHYTHM**
  (темп), **ORBIX Rings**, **OSCILLATOR**, **LIVE** (уровень входа / мастера) и
  **GRAIN 2/3** (случайность). Новые пресеты: *Rhythm, Rings, Oscillator, Live,
  Grain 2/3*. Виден активный пресет (изменённая раскладка становится `USER`);
  описания на русском и английском.
- Обе страницы работают по **Console Controls** BETA 2.0: A — войти/править,
  B — назад, LEFT/RIGHT — изменить, удерживать A + LEFT/RIGHT — быстрая правка.
- README переписан (EN/RU): установка, управление, инструкции по iPhone и
  STICKS & BUTTONS; документация для 1.0.1 перенесена в `docs/LEGACY_1_0_1*.md`.

## Известные ограничения

- Из линии 1.0.1 ещё не перенесены: сокращённое меню SETTINGS и **удаление
  записей внутри SAMPLE** (запланировано).
- Ещё не измерено: нагрузка на CPU резонатора Rings и LIVE на H700,
  Bluetooth MIDI на ROCKNIX, iPhone и USB MIDI вместе на одном OTG-порту.
- Параметры паттернов RHYTHM внутренние; назначается только темп.
- iOS может показать «Аксессуару требуется слишком много энергии»; убирает USB-C
  хаб со сквозной зарядкой PD. KNULLI в этой линии не поддерживается.
