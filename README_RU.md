# GrainBernik

[English](README.md) | Русский

**GrainBernik** — неофициальная адаптация [GrainBrick](https://github.com/ETRNLIAM/GrainBrick)
для **Anbernic RG40XX H**, экран **640×480**, система **KNULLI**.

GrainBrick — инструмент для гранулярной обработки сэмплов, создания эмбиентных
текстур, работы с эффектами и генеративным движком ORBIX. Он предназначен для
живого исследования звука, а не для работы как трекер или обычный лупер.

Оригинал рисует интерфейс для TrimUI Brick в разрешении 1024×768. Адаптер
уменьшает кадр до 640×480, сохраняя пропорции и весь интерфейс. Другие адаптеры
сопоставляют кнопки консоли, подключают USB-запись и расширенные настройки.
Оригинальные файлы приложения и DSP не изменяются и не распространяются здесь.
Для установки нужен официальный ZIP GrainBrick beta 1.0.

**Скачать:** [GrainBernik v0.1.0-beta.2](https://github.com/AlekseyMalykh/GrainBernik/releases/tag/v0.1.0-beta.2).
Архив **patch** предназначен для установки поверх официального GrainBrick,
архив **update** — для обновления уже установленного GrainBernik тремя файлами.
Оригинальное закрытое приложение в архивы не входит.
[Описание релиза на русском и английском](docs/releases/v0.1.0-beta.2.md).

## Статус

На RG40XX H с KNULLI проверены масштабирование, кнопки, вывод и запись через
USB-аудио с Zoom H1n. Владелец подтвердил работу первой версии расширенных
настроек **3 ноября 2026 года**.

Последнее обновление **beta.2** исправляет язык интерфейса: названия меню,
пункты, значения и сообщения остаются на английском, а подсказки следуют
настройке **INFO LANGUAGE**. Предыдущая версия прошла **48 тестов**: 30
логических и 18 с оригинальным ARM64-приложением и DSP. Локализационная правка
beta.2 пока не проходила автоматическую проверку и ожидает повторного теста на
приставке. Это не заменяет проверку всех эффектов на слух и длительную работу.

## Первая установка

1. Скачать из [релизов оригинального проекта](https://github.com/ETRNLIAM/GrainBrick/releases)
   файл `GrainBrick_beta_1.0_TrimUI_Brick_KNULLI.zip`. Автоматический архив
   GitHub «Source code» не содержит самого приложения.
2. Скопировать из официального ZIP папку `grainbrick-beta/` и файл
   `GrainBrick beta 1.0.sh` в `/userdata/roms/ports/`. При подключении карты
   к компьютеру это папка `roms/ports` на разделе **SHARE**.
3. Скопировать все шесть файлов из
   [`rg40xx-h-patch/grainbrick-beta/`](rg40xx-h-patch/grainbrick-beta/)
   в установленную папку `grainbrick-beta/`, заменив загрузчик:

   | Файл | Назначение |
   |---|---|
   | `gb_launch.py` | Загрузчик приложения и адаптеров |
   | `gb_display_fit.py` | Масштабирование интерфейса |
   | `gb_buttons.py` | Сопоставление физических кнопок |
   | `gb_audio.py` | Адаптация USB-записи |
   | `gb_advanced.py` | Встроенный экран расширенных настроек |
   | `gb_advanced_controls.py` | Назначения, сохранение и управление параметрами |

4. Скопировать `GrainBernik Buttons Setup.sh` из
   [`rg40xx-h-patch/`](rg40xx-h-patch/) в `roms/ports/`. При желании также
   скопировать `GrainBernik Audio Check.sh` для диагностики USB-звука.
5. Обновить список PORTS в KNULLI и запустить GrainBrick. При первом запуске
   пройти настройку кнопок по подсказкам на экране. Необязательные шаги
   пропускаются автоматически через несколько секунд.

Приложение требует ARM64 KNULLI с Python 3.12, Pygame и NumPy. Другие модели
консолей и операционные системы отдельно не проверялись.

## Обновление установленного GrainBernik

Для добавления или обновления Advanced Settings достаточно заменить
**`gb_advanced.py`, `gb_advanced_controls.py` и `gb_launch.py`**.

Перед заменой сохраните резервную копию загрузчика и настроек. Не удаляйте
установленную папку: сохраняйте `gb_buttons.json`, `settings.json`,
`sound_state.json`, сэмплы, проекты и записи. Существующие адаптеры звука,
кнопок и экрана, а также дополнительные USB-скрипты для этого обновления
заменять не требуется. Форматировать карту не нужно.

## Кнопки

GrainBrick ожидает номера кнопок TrimUI Brick. Адаптер один раз запоминает
кнопки Anbernic и переводит их события в нужные номера, чтобы подсказки A/B,
L1/R1 и другие соответствовали физическим кнопкам. Поддерживаются крестовина
и аналоговые курки. Сопоставление хранится в `gb_buttons.json`.

Повторить настройку можно через порт **GrainBernik Buttons Setup** либо после
удаления файла сопоставления. `GRAINBRICK_BUTTONS=0` отключает этот адаптер.

## Расширенные настройки

Откройте **SETTINGS → ADVANCED SETTINGS**, нажмите **A** или вправо.
Это встроенная часть программы. В ней четыре независимых подменю:
**Left Stick**, **Right Stick**, **L2 Button**, **R2 Button**.

Все четыре назначения по умолчанию **OFF**. Выключенные органы показаны
приглушённым цветом, но их можно настраивать. Выключение не стирает
назначения и не меняет настройки остальных органов.

| Кнопки | Действие |
|---|---|
| Крестовина вверх/вниз | Выбрать строку |
| Крестовина влево/вправо, A | Изменить значение или открыть подменю |
| B | Назад на один уровень |
| START | Запустить/остановить воспроизведение, оставаясь в меню |
| L1/R1, настроенные TAB−/TAB+ | Закрыть подменю и переключить основные вкладки |

Назначения сохраняются автоматически после изменения, поэтому переход на
другую вкладку их не теряет. Для длинного списка Stick Options есть прокрутка
и номер строки. **Reset to Defaults** требует подтверждения и сбрасывает только
четыре дополнительных назначения, сохраняя штатные настройки звука.

### Пресеты управления

Откройте **Advanced Settings → Presets / Пресеты**. Доступны пять готовых
раскладок и один пользовательский слот **User**. После обновления текущая
раскладка сохраняется: пресет сам по себе не включается.

| Пресет | Левый стик X / Y | Правый стик X / Y | L2 / R2 | Чувствительность / сглаживание |
|---|---|---|---|---|
| Granular | Grain Position / Size | Grain Pitch / Density | Freeze / Reverse | 70% / 60 мс |
| Ambient | Grain Position / Spray | Reverb Mix / Shimmer Amount | Freeze / Reverb Wash | 50% / 180 мс |
| Echo | Delay Time / Feedback | Delay Mix / Reverb Mix | Delay Throw / Reverb Wash | 50% / 100 мс |
| Tape | Tape Saturation / Wow | Grain Pitch / Tape Flutter | Pitch Drop / Bypass | 40% / 140 мс |
| ORBIX Play | ORBIX Rotation / Gravity | ORBIX Bounce / Reverb | ORBIX Toggle / Reverb Wash | 50% / 120 мс |

Готовая раскладка включает четыре органа, использует Spring для стиков
и Hold для кнопок, кроме ORBIX Toggle. Номера физических осей, мёртвая зона
и инверсия остаются вашими. Меняются только назначения: звук, транспорт
и сохранённые проекты не перенастраиваются. Для параметров гранулятора/tape
включите соответствующую штатную обработку; для воспроизведения — START.

- **Применить пресет:** откроется подтверждение с выбранным названием;
  сначала выделена «Отмена». Если User ещё пуст, текущие настройки будут
  автоматически сохранены в него перед первой заменой.
- **Сохранить текущую:** записывает все четыре органа и их параметры в User.
  Перезапись требует подтверждения. Это независимая копия: дальнейшее
  редактирование текущей раскладки её не меняет.
- **Загрузить свою:** восстанавливает сохранённый User после подтверждения.
  Пустой или несовместимый с текущим движком слот недоступен.
- **Reset to Defaults:** сбрасывает текущие назначения, но сохраняет User.

User хранится в `settings.json` и доступен после перезапуска. Выбор других
готовых раскладок не перезаписывает занятый слот. При ошибке сохранения
пресета текущие назначения и User остаются прежними. START и L1/R1 работают
и в списке пресетов, и при подтверждении; уход со страницы отменяет действие.

### Подсказки на русском и английском

Как в штатных меню, заголовок выбранного пункта и его пояснение находятся
**сверху, перед списком настроек**. Подсказки кнопок остаются внизу.

В штатном пункте **INFO LANGUAGE** выберите **RU** или **EN**. Подсказки кнопок,
пояснения выбранного пункта и описательные строки в расширенных настройках
используют этот язык. Названия меню и пунктов, значения, заголовки подтверждений
и сообщения об ошибке сохранения остаются на английском. Изменение применяется
сразу, без перезапуска. Имена эффектов и параметров остаются такими же, как
в самой программе, чтобы их было удобно узнавать.

### Стики X/Y

Горизонтальной и вертикальной осям можно независимо назначить параметр или
**None**. Доступны мёртвая зона (по умолчанию 12%), чувствительность,
инверсия X/Y, режим возврата и сглаживание.

- **Spring:** после отпускания возвращает параметр к значению начала жеста.
- **Latch:** после возврата стика в центр оставляет последнее значение.
  Выключение назначения или вход в экран вне исполнения снимает воздействие.
- **Sensitivity:** при 100% полный ход стика меняет половину диапазона
  относительно значения начала жеста. Достижение границ ограничено движком.
- **Smoothing:** время отклика 0–500 мс, по умолчанию 60 мс. Больше — плавнее;
  0 отключает дополнительное сглаживание адаптера.
- **Physical X/Y Axis:** номера осей SDL; обычно левый стик 0/1, правый 2/3.
  Их можно исправить для другого порядка осей. Оси аналоговых курков,
  определённые калибровкой, зарезервированы.

Список формируется по параметрам установленного движка. В beta 1.0 доступны
**31 назначение** и None:

| Группа | Параметры |
|---|---|
| Grain | Position, Size, Density, Pitch, Spray |
| Delay | Time, Feedback, Mix, Lowpass |
| Reverb | Mix, Size, Decay |
| Shimmer | Amount, Pitch |
| Tape | Saturation, Wow, Flutter |
| Roam | Speed |
| ORBIX | Gravity, Rotation, Bounce, Volume, Attack, Release, Reverb, Balls, Root, Scale, Instrument, Octave, Shape |

Параметры гранулятора и tape требуют включения соответствующей штатной
обработки. XY-назначение само по себе не включает эти модули.

### Управление ORBIX

Можно назначить физику и звук ORBIX на любой стик, например:
**X — ORBIX Rotation, Y — ORBIX Gravity**. Другой стик при этом может менять
реверберацию или параметры гранулятора. Количество шаров, основная нота, лад,
инструмент, октава и форма передаются движку целыми значениями.

Чтобы включать ORBIX кнопкой, выберите **Effect → ORBIX** для L2 или R2.
Hold включает его при удержании, Toggle — по первому нажатию. При снятии
назначения возвращается прежнее состояние ORBIX: уже включённый генератор
не будет неожиданно выключен. Само назначение не переключает транспорт;
для воспроизведения используйте START.

### L2 и R2

Для каждой кнопки отдельно выбираются Enabled, Effect и Mode:

- **Hold:** эффект действует при удержании.
- **Toggle:** нажатие включает, повторное возвращает исходные значения.

| Назначение | Реальное действие |
|---|---|
| Freeze | Штатный Motion Hold: удержание коротких фрагментов, а не спектральная заморозка |
| Reverse | Штатный Motion Reverse внутри звукового потока; файл сэмпла не разворачивается |
| Delay Throw | Временные значения mix 0.65 и feedback 0.6 задержки |
| Reverb Wash | Временные значения mix 0.85, size 0.95, decay 12 с |
| Pitch Drop | Включение гранулятора и понижение на 12 полутонов |
| Bypass | Отключение delay/reverb/shimmer, tape, компрессора и EQ при сохранении воспроизведения |
| ORBIX | Включение генератора с последующим восстановлением прежнего состояния |
| None | Без дополнительного эффекта и перехвата кнопки |

Это обратимые назначения существующих параметров, а не новые алгоритмы DSP.
При выключении восстанавливаются предыдущие значения. Если несколько органов
меняют один параметр, приоритет: левый стик, правый стик, L2, R2. Отпускание
одного не отменяет воздействие другого, который ещё активен.

Управление действует на вкладках GRAIN/FX/TAPE/VISUAL. В Sample/браузере,
Settings, Save, справке и настройке кнопок временные эффекты снимаются,
включая Toggle/Latch. То же происходит при потере фокуса, отключении
контроллера и выходе. После возвращения нужна новая кнопка или центрирование
стика. Настройки сохраняются в разделе `grainbernik_advanced` существующего
`settings.json`; штатные настройки сохраняются рядом с ними.

### Ограничения

В проверенной шине beta 1.0 нет Filter Cutoff/Resonance, Tape Speed и Pan.
Прямой доступ к отдельным Stutter, Tape Stop и Glitch не подтверждён, поэтому
они не предлагаются. Delay Throw/Reverb Wash — наборы значений параметров,
а не новая маршрутизация send/return. При возврате mix в ноль слышимый хвост
эффекта не гарантируется.

## USB-аудио

- Подключите совместимую USB-звуковую карту до запуска программы и выберите
  её в OUTPUT. Вывод работает через штатную систему.
- Для записи выберите **USB AUDIO**. Адаптер перенаправляет фиксированный
  вход оригинала `hw:1,0` на доступную USB-карту через ALSA `plughw`, с
  преобразованием частоты, разрядности и каналов.
- В RG40XX H нет встроенного микрофона: BUILT-IN MIC не работает.
- Проверено с **Zoom H1n**: кабель micro-USB → USB-C с передачей данных,
  подключение к OTG, на рекордере Audio Interface → PC/Mac. Батарейки
  в рекордере делают подключение надёжнее.
- iPhone нельзя использовать как USB-звуковую карту для Linux.
- Для диагностики запустите **GrainBernik Audio Check**: результат появится
  в `grainbrick-beta/audio_check.txt`.

## Дополнительные параметры запуска

Переменные можно добавить в `GrainBrick beta 1.0.sh` перед строкой Python.

| Переменная | Значение | Действие |
|---|---|---|
| `GRAINBRICK_SCREEN` | Например `640x480` | Явно задать разрешение |
| `GRAINBRICK_SCALE` | `smooth` / `fast` | Сглаженное или быстрое масштабирование |
| `GRAINBRICK_FIT` | `0` | Отключить адаптер экрана |
| `GRAINBRICK_BUTTONS` | `0` | Отключить сопоставление кнопок |
| `GRAINBRICK_AUDIO` | `0` | Отключить адаптер USB-записи |
| `GRAINBRICK_USB_IN` | Например `plughw:CARD=H1n,DEV=0` | Принудительно выбрать вход |
| `GRAINBERNIK_ADVANCED` | `0` | Отключить расширенные настройки и назначения |

Журнал запуска: `grainbrick-beta/beta_port_launcher.log`.

## Проверки и обратная связь

Запуск логических тестов:

```sh
python -m unittest discover -s tests -p test_advanced_controls.py -v
```

Проверки с оригинальным ARM64-модулем и подробный сценарий для устройства:
[Advanced Settings](docs/ADVANCED_SETTINGS.md). Они проверяют настоящие классы
ввода/отрисовки, сохранение, снятие эффектов, START/L1/R1, оба языка и работу
ORBIX через оригинальный DSP, включая генерацию из тишины.

Для сообщения о проблеме укажите модель, версию KNULLI и шаги воспроизведения.
Оригинальное приложение бесплатно, но его исходный код закрыт; публичный
beta-релиз не означает открытую лицензию исходников. Материалы и уведомления
о сторонних компонентах находятся в официальном архиве.
